# Example skill

A skill is a procedure the agent loads on demand. Keep it short, keep it specific, and say what it
is *not* for, so the agent does not load it by mistake.

## When to use

Name the trigger. "When the user asks to X" beats "for X-related tasks".

## Steps

1. The first thing to do.
2. The next thing.

## What this is not for

Name the neighbouring skill that owns the adjacent job, so the agent routes correctly.
